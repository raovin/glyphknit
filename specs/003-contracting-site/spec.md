# Project-first contracting site

An engineering buyer can inspect a completed project, try the release-gate demonstration, and discuss a contract with Vin. A visitor can distinguish client projects, earlier employment and independent demonstrations. About explains Vin’s education and a technical decision. The HTML and PDF résumés share anonymous work descriptions and an owner timeline beginning in December 2022.

Preserve existing public URLs and the static export. Provide reusable prompts for identity exploration and private project research. Keep attributable evidence local and transfer only public-safe drafts.

Feature a GlyphKnit client engagement before earlier employment. A buyer reading any case can open an inquiry about that project in one click, remove the reference, and use either an email draft or a copyable message. Optional fields stay out of the message when left empty. Only the public case slug belongs in the page URL.

Organize the case index by project. Keep the working relationship on each detail page. An engagement with only a confirmed team contribution can have a short project brief. Publish individual decisions and outcomes only where the source supports them.

Visitors can complete a local signup with a prefilled fictional identity. They choose Email or SMS and a delivery delay, start registration, wait real elapsed time for a code in a synthetic inbox, and enter that code to complete signup. No real messages are sent. Each run keeps the channel and settings selected at its start; visitors restart to try another run.

The browser check exercises the confirmation screen using supplied synthetic verification responses. The independent delivery check passes when the message arrives at or before the visible ten-second deadline and fails when it arrives later. A late code remains usable for signup, so registration success and delivery timeliness can differ. Link the demo from the case study and both demo listings.
